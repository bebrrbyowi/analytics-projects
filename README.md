## Python + SQL

### Исследование лояльности пользователей Яндекс Афиши

Файл: `project_afisha.ipynb`

Анализ лояльности пользователей Яндекс Афиши по данным о покупках билетов на мероприятия в 2024 году

- Выгрузка данных из PostgreSQL через SQLAlchemy и объединение 290 000+ записей о заказах
- Предобработка и конвертация выручки из тенге в рубли по курсу на дату заказа
- Построение профиля пользователя: даты заказов, устройство, регион, жанр, средний чек и интервалы между покупками
- Исследовательский анализ: сегментация по типу мероприятия, устройству, региону и билетному оператору
- Проверка продуктовых гипотез о влиянии первого заказа на возврат пользователей
- Корреляционный анализ признаков профиля и числа заказов через коэффициент Phi_k
- Формирование рекомендаций по удержанию клиентов и работе с перспективными сегментами
- Python + Pandas + Seaborn + Matplotlib + Phik + SQLAlchemy
  
## ML (Python)
### «TurtleCV: вес по размерам»

Файл: `Tirtle_CV.ipynb`

Разработка линейной модели для предсказания веса зелёной морской черепахи (Chelonia mydas) по её размерам для системы бесконтактного взвешивания TurtleCV

- Предобработка и объединение данных о 8861 особи, отбор только целевого вида и удаление технических признаков
- Обработка пропусков в измерениях ласт и удаление 340 дубликатов
- Исправление аномалий в размерах панциря и фильтрация выбросов по 99-му перцентилю
- Исследовательский анализ распределений и корреляционный анализ признаков через Phik
- Разделение данных на train/val/test (60/20/20) с предотвращением утечки данных
- Обучение и сравнение линейных моделей: LinearRegression, Lasso, Ridge, SGDRegressor
- Применение стандартизации и нормализации признаков для повышения качества
- Оценка важности признаков и написание функции для прогнозирования веса
- Python + Pandas + Scikit-learn + Seaborn + Matplotlib + Phik
