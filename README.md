### Исследование рынка общественного питания Москвы

Файл: `project_moscow_shops`

Исследование рынка заведений общественного питания Москвы по данным Яндекс Карт и Яндекс Бизнес
- Предобработка и объединение 2 датасетов с информацией о 8 000+ заведениях
- Анализ категорий, районов, сетевых и несетевых заведений
- Исследование рейтингов, среднего чека и количества посадочных мест
- Анализ ценовой политики в разрезе районов Москвы и удалённости от центра
- Выявление факторов, влияющих на успешность заведений
- Формирование рекомендаций по формату, локации и ценовой политике нового заведения
- Python + Pandas + Seaborn + Matplotlib + Phik
